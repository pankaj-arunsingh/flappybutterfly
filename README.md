# Flappy Butterfly

A Flappy Bird-style arcade game where you guide a butterfly through flowering vines.

Live demo: **https://pankaj-arunsingh.github.io/flappybutterfly/**

## How to play

- **Flap** with `Space`, mouse click, or tap.
- Fly through the gaps between vines to score. Avoid the vines and the ground.

## Run locally

```bash
git clone https://github.com/pankaj-arunsingh/flappybutterfly.git
cd flappybutterfly
npm install   # or yarn install
npm start     # or yarn start
```

Then open [http://localhost:3000](http://localhost:3000).
